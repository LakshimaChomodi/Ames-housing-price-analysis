# Ames-housing-price-analysis
R-based analysis of the Ames Housing dataset using exploratory data analysis and multiple linear regression with backward elimination to examine factors associated with residential sale prices in Ames, Iowa.
# Factors Associated with Housing Prices in Ames, Iowa

## Project Overview

This project analyzes residential housing prices in Ames, Iowa, using the Ames Housing dataset. It uses exploratory data analysis and multiple linear regression to examine how selected property characteristics relate to sale prices.

The analysis uses data from 1,335 housing transactions and applies backward elimination to develop a reduced regression model.

## Research Objectives

- Explore the housing data and summarize key variables.
- Examine relationships between property characteristics and sale prices.
- Fit a multiple linear regression model.
- Use backward elimination to identify a reduced set of predictors.
- Check model assumptions using diagnostic plots and statistical analysis.

## Predictors Examined

The analysis considers characteristics including:

- Overall quality
- Log lot area
- Year built
- Total basement area
- Ground living area
- Number of rooms above ground
- Garage area

## Methods and Tools

- **Statistical methods:** Exploratory data analysis, correlation analysis, multiple linear regression, backward elimination, and model diagnostics
- **Software:** R

## Repository Contents

This repository contains the analysis code and supporting project materials.

## Scope

This is an academic analysis of housing transactions. The findings describe relationships in the dataset and should not be interpreted as proof that a property characteristic causes a change in sale price.
